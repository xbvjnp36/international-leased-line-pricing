## 同一条线路，报价为什么能差一倍？五个定价因素

1. **线路目的地**。香港、日本、新加坡等亚洲线路距离近、资源多，成本最低；美国、欧洲线路跨境距离更远，价格高一档；中东、非洲方向线路资源有限，报价最贵。
2. **带宽大小**。国际专线按M计费，带宽翻倍费用基本跟着翻倍。别一上来就报100M——普通海外办公，5M-10M可能已经够用；跨境直播、大批量数据传输才需要更高带宽。
3. **专线类型**。常见的有国际互联网专线、MPLS VPN、IEPL国际专线和SD-WAN跨境组网四种。传统专线（IEPL/EPL）稳定性最高，价格也最高；SD-WAN部署灵活、上线快，价格明显更低，适合要快速拓展海外业务的企业。
4. **服务等级**。要不要99.9%可用率的SLA、7×24小时技术支持、网络监控、多线路备份，都会加钱。以中国电信美洲公司的以太网专线产品为例，它的标准配置就是99.9%或更高的网络可用性保障，接入速率可从2Mbps做到10Gbps——这类写进合同的保障，是价格里值钱的部分。
5. **合同周期**。签一年或更长的合同，通常能拿到比月付更有吸引力的价格，不少服务商还支持带宽随业务增长灵活升级。

## 两种合法办理渠道，价格能差出一截

企业跨境联网，合法的接入方式只有两种。

**渠道一：直接找电信、移动、联通三大运营商申请国际专线。**物理专线接入，速度快、稳定性最好，主流报价400-500元/M/月。但运营商主要面向国企、事业单位受理，施工周期长，整体资费也贵，一般中小企业很难办下来。

**渠道二：通过持有电信主管部门颁发的电信业务经营许可的第三方服务商办理**，常见形态是SD-WAN跨境组网或独享合规专线。接入方式更灵活，硬件CPE设备、软件客户端都支持，价格比运营商渠道低不少，部署周期也短。

## 询价前，把这五个问题问清楚

专线是定制服务，报价单之外的信息才决定你后面会不会踩坑：

1. **资质**：对方有没有工信部颁发的电信业务经营许可？这是合法性的底线，市场上无资质转卖的线路不少，被查处时业务说断就断。
2. **独享还是共享**：同样标5M，独享和共享的体验差很远，价格也不一样，问清楚并写进合同。
3. **SLA条款**：99.9%可用率是运营商级标准，第三方能不能承诺？故障赔偿怎么算？
4. **额外费用**：专线费用可能不含政府或其他税费，设备、施工、维护是否另算，让服务商一次性列全。
5. **续约价格**：首年优惠价和续约价是否一致，签长约能降多少，直接决定第二三年的真实成本。

## 常见问题

**5M带宽到底够不够用？**普通办公场景（网页、邮件、ERP、日常视频会议）基本够。要多路高清直播、大批量传输数据，就按10M以上考虑，或者直接让服务商按你的业务量测算。

**国际专线和企业VPN有什么区别？**专线是物理或逻辑独享的通道，稳定性和安全性都更高，有SLA保障；VPN价格低，但连接稳定性和安全性比不了专线。企业长期跨境业务，不建议拿VPN当主链路。

**为什么运营商不太愿意接中小企业的单？**一是资费门槛高，二是运营商国际专线长期主要面向国企和事业单位受理，中小企业通过持牌第三方渠道办理更现实。

**带宽以后能升级吗？**可以，主流服务商都支持灵活增速，业务涨了再升，不必一步到位买最大带宽。
